【起動方法】 UnityのAssets>Scenes>Developにmapというsceneがあるので、そのsceneに移動し、上の再生ボタンを押すとゲームをプレイできます 
【操作方法】 矢印キーで移動、マウスで視点移動、入力はキーボード
脱出までの流れ
1．スタートすると左側に板がたてつけられており、それに近づき、クリックする
2．問題が表示される。内容は「赤い文字を順番に並べるとできる言葉は？」
3．ドアに近づきクリックすると入力バーが表示される
4．正しい文字を入力する（ひらがなで「えいりあん」）※入力文字が表示されないが問題はない
5．もう一度ドアをクリック
6．「clear」と画面に表示される
